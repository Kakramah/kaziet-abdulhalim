# كازية عبد الحليم للمحروقات

الموقع الرسمي لكازية عبد الحليم للمحروقات في جبلة، شارع الفوار.

## المحتوى

لوحة حالة توفر البنزين والمازوت الحية، خريطة الموقع، معرض الصور، ونموذج التواصل.

## التقنيات

HTML · CSS · JavaScript — بلا مكتبات خارجية.

## النشر

`https://kakramah.github.io/kaziet-abdulhalim/`

## لوحة التحكم داخل الصفحة الرئيسية

- رمز القفل الصغير في ذيل الصفحة يفتح نافذة دخول المدير، وبعد الدخول تظهر اللوحة فوق الصفحة ويظهر زر **لوحة التحكم** في الشريط العلوي.
- الملفات: `admin-panel.js` (المنطق) و`index.html` (النافذة) و`style.css` (آخر قسم). `admin.html` المستقل باقٍ باباً احتياطياً.
- إخفاء الزر راحة للزائر لا حماية. الحماية الفعلية سياسات RLS في Supabase وصفة `app_metadata.kaziet_admin` (راجع `ADMIN_SETUP.md`): أي حساب بلا هذه الصفة يُرفض في الكتابة ولو فتح اللوحة.
- نتيجة نشر الحالة تظهر في الصفحة خلف النافذة فوراً، وتتغير صورة الواجهة دون إعادة تحميل.
